# ГАС «Правосудие»: границы интеграции

Дата проверки: 5 августа 2026 года.

## Подтверждённый пользовательский сервис

Официальная публичная форма поиска по территориальной подсудности:

- https://sudrf.ru/index.php?id=300

Форма предназначена для самостоятельного поиска пользователем. На дату проверки не найдены официальная документация публичного API и открытый машиночитаемый набор Судебного департамента, который позволял бы надёжно сопоставлять полный адрес с конкретным судом или мировым судебным участком.

При прямом серверном обращении в ходе проверки наблюдался ответ HTTP 403. Доступность пользовательской страницы через браузер не подтверждает наличие API и не разрешает автоматический сбор данных.

## Запрещённые способы

В production запрещено:

- парсить HTML страниц ГАС «Правосудие»;
- использовать недокументированные параметры формы как API;
- обходить HTTP 403, защиту от автоматических запросов или географические ограничения;
- встраивать сервис через `iframe` без официального подтверждения допустимости;
- создавать собственную непроверенную базу территориальной подсудности;
- считать суд проверенным по домену ссылки, названию суда или подтверждению пользователя.

## Безопасный порядок v1

1. Пользователь вводит регион и полный адрес.
2. ПравоПоиск открывает официальный поиск ГАС «Правосудие» в новой вкладке.
3. Пользователь самостоятельно переносит найденные реквизиты суда.
4. Интерфейс сообщает, что ПравоПоиск не проверил реквизиты и территориальную подсудность автоматически.
5. Иск, ходатайство, нотариальный проект, копия, печатная версия и DOCX остаются черновиками. Судебные DOCX получают префикс `CHERNOVIK-`.

Ни `courtSearchConfirmed=yes`, ни ссылка на `sudrf.ru`, ни заполненное название суда не меняют статусы `requiresLegalReview=true` и `filingReady=false`.

## Регионы

ФНС подтверждает, что ФИАС является федеральной государственной информационной системой и официальным источником Государственного адресного реестра:

- https://www.nalog.gov.ru/rn77/service/fias/

Сам сервис ФИАС и пригодный для синхронизации перечень субъектов не открылись в среде проверки 5 августа 2026 года. Поэтому список регионов не создавался из памяти или вторичных источников. В v1 регион вводится вручную и используется только как параметр официального поиска. Изменение региона очищает ранее введённые реквизиты суда.

## Вопросы для ФГБУ ИАЦ

До автоматизации необходимо письменно уточнить:

1. Существует ли документированный публичный API поиска территориальной подсудности.
2. Есть ли официальный открытый набор границ и адресов судебных участков, включая номера домов.
3. Разрешено ли коммерческому сервису выполнять машинные запросы и кэшировать ответы.
4. Какие идентификаторы суда и участка являются стабильными.
5. Каковы лимиты запросов, требования к авторизации и правила обновления данных.
6. Предусмотрены ли уведомления об изменении границ и реквизитов судов.
7. Разрешено ли встраивание пользовательской формы и на каких условиях.
8. Какой официальный порядок исправления ошибочных данных.

Официальные контакты для будущего обращения:

- `info@cdep.ru` — Судебный департамент при Верховном Суде РФ.
