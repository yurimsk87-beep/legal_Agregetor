- 43/43 маршрута включены в `LEGAL_ROUTE_STANDARD_V1`, имеют сценарии и связи с документами; это техническая интеграция, **не** юридическая сертификация.
- 14 трудовых, 5 новых семейных, 24 наследуемых семейных маршрута.
- Три GitHub Actions прошли на базовом коммите `a239d57`. Новые изменения требуют повторной проверки.
- В коде добавлены PostgreSQL-модель архива, шифрование AES-256-GCM, API с разграничением доступа по пользователю, кабинет для просмотра и удаления версий, а также проверки криптографии. **Это подтверждает наличие реализации, но не заменяет runtime-приёмку миграций, восстановления после перезапуска и контроль безопасной конфигурации ключа.**
- Реальный AI-provider smoke test и экспертная юридическая приёмка **не завершены**.
- На старых семейных маршрутах `LEGAL_REVIEW_ONLY` в каталоге — консервативная метка, не фактический результат генератора.
- До завершения юридической приёмки `filingReady=false` обязателен.

## Восемь критериев для каждого маршрута

Для каждого `categorySlug/problemSlug/scenarioKey` отдельно проверить:

1. Сценарий достижим через публичный URL, ведёт к корректному документу или безопасной инструкции.
2. Юридический валидатор покрывает положительный, отрицательный, неполный, исключительный и срочный кейсы. Неизвестные факты не заменяются догадками.
3. Анкета валидирует поля, изменение и возврат; личные данные не попадают в URL и публичную аналитику.
4. Генератор возвращает верный `resultKind`, исходные данные и текст соответствуют результату; `filingReady=false` до разрешённой проверки.
5. Создание PDF разрешено только при явном `pdfAvailable === true`; PDF привязан к `versionId`, несохранённые правки блокируют экспорт.
6. Ошибки, отсутствие данных, экстренные и юридически неоднозначные случаи обрабатываются безопасно.
7. Страница, SEO, мобильный интерфейс и клавиатурная доступность соответствуют реальному типу результата.
8. Автотесты и экспертная юридическая проверка: первоисточники, сроки, подсудность, полномочия, госпошлина, порядок подачи.

Статусы проверки: `NOT_CHECKED`, `AUTOMATED_PASS`, `MANUAL_PASS`, `LEGAL_REVIEW_PASS`, `BLOCKED`. Не повышать статус на основании наличия маршрута в реестре, успешной сборки или только текстового поиска в исходнике.

5. Юридический аудит и финальные E2E, безопасность, миграции и локальная сборка. Production после отдельной приёмки.
